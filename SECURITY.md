# Security Policy

## Supported versions

Security fixes are provided for the latest v1.x release.

| Version | Supported |
| --- | :---: |
| 1.x | Yes |
| Earlier versions | No |

## Reporting a vulnerability

Please use [GitHub's private vulnerability reporting](https://github.com/Halo1211/cloud-folder-browser-reimagined/security/advisories/new). Do not include working credentials, private share links, or personal download history in a public issue.

Include the affected version, operating system, reproduction steps, impact, and any suggested mitigation. Reports will be acknowledged after they can be reproduced and scoped.

## Handling diagnostic data

Before sharing logs, remove tokens, passwords, private URLs, file names, proxy credentials, and account identifiers. Crash dumps may contain secrets and should never be attached to a public issue.
