# WebDAVClient

Vendored C# WebDAV client adapted for Cloud Folder Browser Reimagined.
It supports asynchronous listing, transfers, authentication, and file operations.

Upstream: [saguiitay/WebDAVClient](https://github.com/saguiitay/WebDAVClient),
originally based on [kvdb/WebDAVClient](https://github.com/kvdb/WebDAVClient).

This source includes application-specific changes for AllSync shares, response
parsing, URL handling, and network configuration. The upstream NuGet package
does not contain all changes made in this repository.
