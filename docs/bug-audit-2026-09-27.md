# Bug audit — September 27–29, 2026

This audit examined a local checkout of Cloud Folder Browser Reimagined through
baseline tests, module review, failing reproductions, fixes, regression tests,
and UI rendering checks. The `diagnosing-bugs` skill provided the automated
reproduction workflow. The `code-review` skill was read, but its review against a
fixed commit was not applied because this request covered the whole program.
Changes from earlier passes were preserved throughout the audit.

## Fixed bugs

| Area | Trigger and previous impact | Corrected behavior |
| --- | --- | --- |
| HTTP overwrite | A shorter final file was moved to `.part` and reused as a resume prefix, mixing old and new bytes. | Only `.part` files supply resume bytes; old final files are not reused. |
| Existing-file preservation | A failed overwrite occurred after moving or deleting the old final file. | The old file remains until its replacement is complete and validated. |
| HTTP and MEGA overwrite policy | Never overwrite was respected only when sizes matched. | The policy applies to every existing final file; an explicit sync Overwrite action still takes precedence. |
| Local paths | The HTTP constructor converted literal `%27` to an apostrophe, changing the history destination. | Local paths retain their literal text and use `Path.GetFullPath`. |
| Empty-file metadata | A file with initially unknown size remained unknown even when the response proved it was empty. | Size, including zero, is recorded from headers or a completed transfer. |
| HTTP 206 responses | Partial responses without `Content-Range` were accepted as complete files when size was unknown. | Range unit, start, end, total size, and response length are validated before writing. |
| Complete `.part` validation | A partial file with the expected size was promoted without remote validation. | HTTP validation still runs; a qualifying 416 response checks size and available remote checksums. |
| WebDAV file names | An `href` such as `a+b.bin` became `a b.bin`. | URI path decoding preserves `+`. |
| WebDAV hidden flag | `ishidden=0` was interpreted as hidden. | Boolean and numeric values are evaluated. |
| Incomplete WebDAV responses | A response without `href` caused `NullReferenceException`. | Responses without a path identity are skipped. |
| WebDAV property status | Failed `propstat` groups could overwrite successful metadata. | Only successful property groups are applied; compatible servers that omit status remain supported. |
| WebDAV resource type | A collection was missed when another element preceded `collection`. | Every `resourcetype` child is checked; stream and string parsing share one implementation. |
| AllSync/Qloud decoding | An already decoded query path was decoded again, changing `Library+A`. | Query paths are decoded once; `href` paths use URI decoding in portable and legacy loaders. |
| AllSync size | Missing `getcontentlength` was treated as a known empty file. | Missing size is represented by `HasKnownSize=false`. |
| Sync preview collisions | Preview compared raw cloud paths while downloads used sanitized Windows paths. | Preview compares sanitized local targets, including renames. |
| Cloud file selection | Remote names differing only by case were silently merged. | Both remain available for review; Windows target collisions can be resolved in preview. Repeated folder selections are still deduplicated. |
| Local file counts | Counts stayed at zero despite successful scans. | Direct and recursive counts are calculated from scanned files. |
| Checksum snapshots | Callers could mutate a `RecordFileAsync` result and change the in-memory baseline. | The method returns an independent copy. |
| JSON persistence | Null entries in accounts, history, or checksum lists caused crashes. | Null entries are skipped without losing usable entries. |
| DNS endpoint validation | Userinfo, paths, queries, and fragments were accepted but ignored. | Those forms are rejected; valid IP and IP:port forms remain supported. |
| Segment cancellation | A failed worker did not cancel siblings until `Task.WhenAll` finished. | A failure immediately cancels siblings and preserves the original error. |
| Segment manifests | Null identity, validator, or block fields broke resume. | Invalid manifests, including null block entries, are rebuilt. |
| Transfer artifact collisions | One file could target another file's `.part`, assembly, manifest, or segment path. | Every batch target is validated before clients or transfers are created; preview uses the same validator. |
| File/directory collisions | A batch could target both `file.bin` and `file.bin/child.bin`, or write inside transfer artifacts. | Parent-directory and artifact collisions are rejected regardless of order or case; a standalone `.part` name remains valid. |
| Repeated HTTP/MEGA Start | Starting again reset Completed/Skipped to Queued and disrupted active scheduling. | Start runs once per instance and preserves history status. |
| Worker controls | Accepting no progress workers left the queue unable to finish. | Constructors require at least one worker, a label per worker, and a summary label. |
| Backup import ordering | Settings changed before invalid provider proxy rules were rejected. | Documents and rules are validated before settings mutate. |
| Backup payload validation | Missing settings, NaN tolerance, or invalid global DNS/proxy endpoints survived decrypt and could be applied. | Decrypt and Apply share document and network validation. |
| Saved proxy rules | Null JSON entries crashed HTTP handler creation. | Null rules are ignored during load/save. |
| Account fields | Null encrypted secrets or optional fields caused load/upsert crashes. | Unreadable secrets become empty; user/server fields are normalized and secret kind defaults to token. |
| Partial checksum manifests | A single invalid path, such as a NUL character, prevented valid baselines from loading. | Invalid paths are skipped while valid entries remain verifiable. |
| Windows device names | COM/LPT names using superscript digits ¹, ², or ³ bypassed sanitization. | Those device-name variants receive an underscore prefix. |
| PAR2 result reporting | A `.par2` file was reported repaired even when repair was disabled. | Recovery success is reported only after repair completes. |
| Resolver initialization | One provider's initialization failure stopped automatic routing despite available alternatives. | Supported initialization failures participate in fallback. |
| Resolver timeouts | Provider request timeouts were treated as cancellation of the entire job. | Timeouts fall back unless the user's cancellation token is canceled. |
| Stop and queued history | Stopping before Start or with queued files left Queued statuses, sometimes after completion was signaled. | HTTP and MEGA persist Paused queue entries before completion; Start after Stop does not restore Queued. |
| Cancellation after commit | Canceling ZIP extraction downgraded a complete download to Paused. | Post-processing cancellation becomes a Completed-status message; the final file remains available for HTTP and MEGA. |
| PAR2 selection | `film.zip` could select `film2.par2`, `filmography.par2`, or `film.7z.par2`. | Matching uses exact base/full names and the `.vol<number>+<number>` pattern. |
| Web index case | `A/` and `a/` were considered the same loop; differently cased roots were accepted. | h5ai and The Trove preserve remote path case for visits and root boundaries; hosts remain case-insensitive. |
| Web index size units | Unknown units such as XB or non-size text became known byte counts. | Unsupported units and non-finite values produce unknown size; supported decimal/binary units still parse. |
| Remote identity in preview | Encoded/literal spaces, `%2F`, and trailing spaces were merged before local-target review. | Remote identity is preserved; only repeated folder selections are deduplicated. |
| Default cloud folder | `new CloudFolder()` left file/subfolder collections uninitialized. | The default constructor creates a usable empty folder. |
| FogLink timestamps | Single-file and tree/flat loaders swapped creation and modification dates. | Both timestamps retain their metadata meaning. |
| FogLink unknown size | Null size became known zero, rejecting nonempty downloads. | Missing size remains unknown; explicit zero remains known. |
| FogLink flat ordering | Children preceding parents were skipped; the first node was assumed to be the root. | ID/ParentId relationships define the tree independently of response order; duplicate IDs, ambiguous roots, and unreachable nodes are rejected before replacing the model. |
| FogLink folder sizes | Aggregate folder sizes were treated as direct-file sizes and added again. | Totals are calculated from files and subtrees without double counting. |
| FogLink folder names | Trailing spaces/dots were removed while constructing remote paths. | Remote paths retain original names; Windows sanitization applies to local targets. |
| History resume size | Missing `HasKnownSize` made unknown zero look empty and deleted resumable `.part` files. | Size state survives UI retry. HTTP tests verify `Range: bytes=8192-`, exact bytes, the same history ID, and final known size. |
| History resolver requirement | Missing `RequiresLinkResolver` let retries request a share page as a file. | Resolver requirements survive history retry; only resolved URLs are downloaded. |
| Invalid network modes | Unknown DNS provider, DNS transport, and proxy enum values passed validation. | Undefined modes are explicitly rejected. |
| UI node copies | Flat-list copies retained display size but lost bytes, path, and selection state. | Copies retain metadata, timestamps, and checkboxes. |
| UI sorting | Rounded MB text and date-only values made distinct sizes/times compare equal. | Sorting uses original bytes and timestamps; local folders are recognized through `IFolder` and precede files. |
| Flat-view switching | Root files without a `LinkedNode` caused `NullReferenceException`. | Root file nodes are linked and preserve selection in both directions. |
| Sync result totals | Root file sizes were counted twice; a 12-byte fixture displayed 17 bytes. | Root totals sum displayed files exactly once. |
| Partial folder selection | Synthetic folders with `Tag=null` were treated as files under a mixed root. | Non-file nodes are traversed as folders and selected files are collected. |
| FlareSolverr cookies | Null entries crashed; empty domains matched all hosts; invalid names/values produced malformed headers. | Malformed entries are skipped, domains are required, and domain/path/Secure rules and valid empty values remain supported. |
| Cross-share retry | AllSync/Qloud entries from different hosts/shares shared the first entry's credentials. | Retry grouping includes authority and share ID while preserving same-share batching. |
| JDownloader URLs | Decoding `%23`, `%3F`, `%26`, `%2B`, and `+` changed exported paths/queries. | Original URL encoding is retained; unknown size is `-1` and known empty size is `0`. |
| Shared export directory | Export deleted all existing `Links` contents, including user subdirectories. | ZIP files are written through unique temporary files without using or deleting `Links`; failed exports leave no partial ZIP. |
| Export destinations | Root names such as `..` escaped `linkcontainers`; device names were sanitized inconsistently. | Export folders use the downloader's Windows sanitizer, with a unique ZIP name per export. |
| Segment range units | Probe and worker accepted `Content-Range: items ...` as bytes. | Non-byte units are rejected, allowing single-stream fallback. |
| Probe checksums | Content-MD5 for a one-byte response was used to validate the complete file. | Partial-content hashes are not complete-file hashes; representation headers such as Digest still validate. |
| Segment resume validators | Missing or weak ETags allowed old blocks to mix with changed same-size content. | Reuse requires a strong ETag or Last-Modified. Without either, blocks restart. Matching strong ETags and weak ETags with Last-Modified still resume. |
| Share password cache | Passwords were plaintext JSON in settings. | The cache uses DPAPI, dedicated entropy, and a version prefix; normal startup migrates legacy values without affecting UI snapshot settings. |
| Password cache scope | Share IDs alone reused passwords across hosts, schemes, and ports. | Keys include authority and case-sensitive share ID. Legacy entries remain readable but are not sent automatically. |
| Credential cache backups | Raw DPAPI backup values could not be restored by another Windows user. | Capture stores portable JSON inside AES-GCM; Apply protects it for the destination user. Invalid caches are rejected before settings change. |
| External process cancellation | Cancellation during stdin writing preceded cleanup and left the process running. | Input, exit waiting, and output reading share cleanup; failed/canceled processes are terminated and awaited. Pre-canceled tokens prevent launch. |
| ZIP junctions | Destination junctions redirected extraction outside the intended root. | Target components are checked for reparse points before writing; two fixtures preserve outside sentinels. |
| ZIP alternate data streams | `keep.txt:hidden` created a hidden NTFS stream. | Unsafe Windows components, including colons, device names, and trailing-dot/space aliases, are rejected. |
| Default local folder | `LocalFolder()` had null collections and failed when adding or aggregating. | Collections, name, and path are initialized. |
| Limiter cancellation | Pre-canceled calls took slots; canceled waiters left reservations for seconds. | Cancellation is checked before booking, and only available slots are taken. Canceled waits do not delay later transfers; aggregate limits remain tested. |
| Bandwidth overflow | Out-of-range KiB/s multiplication became negative/zero and disabled limiting. | Unrepresentable byte rates throw `ArgumentOutOfRangeException`. |
| HTTP 416 validation | `items */1024` or `bytes 0-1023/1024` promoted `.part` files. | Promotion requires an unsatisfied byte range with matching length and existing size/checksum validation. |
| Byte-range case | Valid uppercase `Content-Range: BYTES ...` was rejected. | Byte units are case-insensitive, following [RFC 9110](https://www.rfc-editor.org/rfc/rfc9110.html#section-14.1). |
| Range metadata on HTTP 200 | Inapplicable Content-Range overrode Content-Length and rejected full files. | Range metadata applies only to 206; 200 uses full content length. |
| Download content encoding | Gzip responses could be stored as ordinary files when size was unknown. | Requests ask for identity encoding; other response encodings are rejected before writing/promotion. |
| Short DNS TTL | Zero/one-second TTLs were extended to five seconds, reusing stale addresses. | Zero TTL is not cached and positive TTL is not extended. A UDP fixture returns a different IP on the next query, following [RFC 1035](https://www.rfc-editor.org/rfc/rfc1035.html#section-3.2.1). |
| Interrupted secure DNS | EOF in one address family aborted resolution despite a successful other family. | I/O failures are handled per query, preserving valid addresses and propagating user cancellation. |
| History write failure | Upsert/remove mutated memory and input timestamps before disk persistence. | A replacement list is saved first; state and caller timestamps update only after replacement succeeds. |
| Checksum write failure | A new in-memory baseline was published despite manifest write failure. | The replacement dictionary is saved before publication; failed writes preserve the old or absent baseline. |
| Folder cache subtypes | Untrusted `$type` selected types outside the cloud tree, such as LocalFolder. | The binder accepts exactly CloudFolder from the application assembly, following [Json.NET guidance](https://www.newtonsoft.com/json/help/html/serializationsettings.htm). |
| Folder cache shape | Null Files/Subfolders or children survived deserialization and crashed later. | An iterative tree validation runs before model loading; valid legacy caches remain readable. |
| Saved MEGA tokens | `$type` selected subclasses; empty IDs or missing/short keys were accepted. | Concrete token deserialization ignores payload type selection and validates IDs and 16-byte master keys before authentication. |
| Local scan races | Files disappearing before Length access aborted scans and could be counted prematurely. | Inaccessible files are skipped without increasing counts or failing the scan. |
| Folder cache write failure | SaveToJson overwrote the destination directly and could corrupt saved lists. | Same-directory temporary writes replace the destination only when complete, preserving old bytes on failure. |
| Account write failure | Upsert changed caller activation/timestamps before disk persistence. | Caller state changes only after the account data is saved. |
| Failed saved-list loading | Invalid JSON replaced the active root with an empty model while the old UI remained. | New root, folder list, and LoadedFromFile state are prepared before publication; failures retain the previous model. |
| Corrupt history retry | Empty/relative/invalid destinations and negative sizes reached retry. | UI filtering precedes grouping; ToRetryFile requires HTTP(S), nonnegative size, and a valid absolute file path. Missing legacy names can be inferred. |
| Web index root boundaries | Nested encoding of separators or `..` bypassed prefix checks after server decoding. | Paths that change segments/separators during decoding are rejected; encoded spaces remain supported. |
| Malformed index links | One unparseable href aborted h5ai/The Trove loading. | Bad rows are skipped while later valid entries continue. |
| Provider plugin matchers | A throwing CanHandle prevented other providers from matching. | Failures go to debug output and matching continues. |
| DNS question mismatch | Matching transaction IDs allowed unrelated type/class/host/opcode responses. | Questions and opcodes are checked before processing answers, following [RFC 1035](https://www.rfc-editor.org/rfc/rfc1035.html). |
| DNS answer owners/CNAME | Unrelated A/AAAA owners and invalid compression pointers were accepted; alias TTL did not constrain caching. | Names use bounded backward pointers; only requested or reachable CNAME owners contribute addresses, with minimum alias/address TTL. |
| FlareSolverr target schemes | Browser requests accepted file URLs; cookie headers accepted FTP or threw on relative URIs. | Targets and cookie requests require absolute HTTP(S) URIs. |

missing historical resolver metadata for other providers cannot always be
reconstructed.

Pass five introduced the `cfb-share-credentials:v1:` DPAPI settings prefix. The

encrypted payload. MEGA export uses existing URLs and no longer opens an unused

Pass six used hidden PowerShell process fixtures and checked only their own
child PIDs after cancellation. UDP tests used real loopback sockets; secure DNS
used an internal transport seam for deterministic wire responses and I/O

Pass seven's failing-write fixtures operated only on temporary test data; no
user files were changed. Model tests verified that an invalid cache preserves
the loaded folder. Pass eight retained share credential grouping's existing
contract and filtered corrupt entries at the UI boundary. Pass nine exercised

Cancellation after commit was reproduced through a resolver callback immediately
after promotion of the final file and before ZIP extraction. MEGA Stop-before-
Start tests did not need external requests; PAR2 selection tests stopped at tool
path validation.

## Verification limits

- HTTP/WebDAV tests used loopback servers and controlled fixtures. MEGA overwrite
  checks did not require a live account or network.
- OAuth login, live transfers across all providers, external DNS/proxies,
  FlareSolverr, 7-Zip, PAR2, and JDownloader were not verified end-to-end against
  real services.
- Render checks did not cover every DPI, resolution, theme, or navigation path.
- This audit does not prove the absence of all bugs or constitute an exhaustive
  security audit. Package advisories were checked in pass five; copied vendor
  code and unknown advisories were outside that check.
- Old downloads written directly to final paths no longer supply resume bytes;
  new transfers restart to avoid mixing versions. `.part` resume remains
  supported.
- Segment resume without a strong ETag or Last-Modified restarts blocks.
  Single-stream `.part` resume without a remote version validator still does not
  prove representation identity; available remote checksums are checked.
- Legacy password entries without authority need one new password entry to
  establish server scope. Use `.cfbackup` to transfer credentials between Windows
  users; raw DPAPI cache copies are not portable.
- Export tests verified ZIP contents, URL encoding, sizes, isolation, and partial
  failure. Actual JDownloader imports and every live provider were not tested.
- Junction and Windows-name protections apply to the built-in ZIP extractor;
  external 7-Zip follows that binary's behavior. Concurrent path changes, hard
  links, and every filesystem combination were not covered. Built-in extraction
  checks cancellation per entry, not during copying a single large entry.
- Cached trees and tokens used local fixtures. Live MEGA login and every legacy
  cache format outside the tests remain unverified. Later filesystem races can
  still occur after a local scan snapshot and are handled when files are used.
- DNS wire fixtures and loopback/internal seams do not cover every public
  resolver's CNAME/cache behavior. FlareSolverr tests checked schemes and cookie
  selection, not a live FlareSolverr service.
